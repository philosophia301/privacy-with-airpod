# privacy-with-airpod

AirPods를 착용한 사용자가 고개를 돌리거나 자리를 벗어날 때 Mac 화면을 블러 처리하는 앱 프로젝트임.

좌우 외장 모니터에서 고개 각도에 따라 화면 일부의 블러가 변하는 애니메이션도 요구에 포함됨. 고개 방향에 따라 선명한 영역과 블러 경계가 연속 이동하며 화면 자체는 기울이지 않음.

관리는 macOS 메뉴 막대에서 제공함. 모니터별 방향 대응·메뉴 구성·가림 중 관리 메뉴 유지는 승인됐음. 시작·복귀·실패 흐름은 spec에서 함께 결정 중이며 구현 방법은 자율 위임됐음.

현재는 **첫 실험 앱 구현·검증 단계**임. [빌드와 실행 방법](docs/development.md)을 제공하며, AirPods만으로 자리 이탈을 얼마나 잘 구별할 수 있는지는 실기기 검증 전임. 자동 기립·이탈 보호는 아직 연결하지 않았음.

제품 행동을 먼저 합의하고 필요한 기술 가정을 작은 실험으로 확인한 뒤 앱을 구현함. 권한·실패 시 동작·블러 해제 방식은 spec의 결정 후보이며 기본값으로 확정하지 않았음.

현재 화면 보호는 Blur Lab에서 확인한 색조 없는 실시간 가변 블러를 Privacy AirPods 본체에 통합한 경로임. 화면 캡처 없이 독립 합성 공간에서 고개 방향에 따른 경계를 적용함. Lab도 같은 출력 코드를 사용하며 비교 진단용으로 유지함. 비공개 macOS API에 의존하므로 OS 호환성과 배포 검증은 별도임. 통합 검증 범위는 [개발 안내](docs/development.md#본체-통합--2026-09-15)를 참조함.
